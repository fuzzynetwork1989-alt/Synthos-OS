# App Assets

This directory contains placeholder assets for the Synthos OS mobile app.

## Required Assets

### Icons
- `icon.png` - App icon (1024x1024px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (16x16px)

### Splash Screens
- `splash.png` - Splash screen (1284x2778px for iPhone X)

## Asset Generation

These are placeholder files. For production, you need to:

1. Create proper app icons using your brand design
2. Generate multiple sizes for different platforms
3. Use tools like:
   - [Expo Asset Tools](https://docs.expo.dev/guides/assets/)
   - [App Icon Generator](https://appicon.co/)
   - [MakeAppIcon](https://makeappicon.com/)

## Asset Requirements

### iOS
- Icon: 1024x1024px
- Must follow Apple Human Interface Guidelines
- Rounded corners automatically applied by iOS

### Android
- Adaptive icon: 1024x1024px (foreground layer)
- Background color specified in app.json
- Must follow Android Material Design guidelines

### Web
- Favicon: 16x16px, 32x32px, 192x192px
- Apple touch icon: 180x180px

## Current Status

Placeholders are provided for development. Replace with production assets before app store submission.
